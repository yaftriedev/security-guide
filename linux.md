# Privacidad en Linux

Linux te da más control sobre el sistema, pero usar software libre no garantiza privacidad ni seguridad por sí solo. Importan también las actualizaciones, la configuración, las aplicaciones que instalas y los servicios en línea que utilizas.

Para empezar, elige una distribución mantenida y fácil de actualizar; Fedora es una opción recomendada para nuevos usuarios. Mantén el sistema al día, descarga programas desde los repositorios oficiales y activa el cifrado del disco durante la instalación, si está disponible. Linux también tiene limitaciones: el arranque verificado y el aislamiento de aplicaciones no siempre son tan sólidos o sencillos como en otros sistemas. 

# Apps Open Source

- [**LibreOffice**](https://www.libreoffice.org/): suite ofimática para crear y editar documentos, hojas de cálculo, presentaciones y dibujos. Es compatible con muchos formatos, incluidos los de Microsoft Office.
- [**Thunderbird**](https://www.thunderbird.net): aplicación para administrar varias cuentas de correo, calendarios y contactos desde el ordenador. Puede ampliarse con complementos.
- [**VLC**](https://www.videolan.org/index.html): reproductor multimedia compatible con numerosos formatos de vídeo, audio y subtítulos, sin necesitar muchos códecs adicionales.
- [**GIMP**](https://www.gimp.org/): editor de imágenes para retocar fotografías, trabajar con capas y crear gráficos. Puede servir como alternativa libre para tareas de edición habituales.
- [**Inkscape**](https://inkscape.org/): herramienta de dibujo vectorial para crear logotipos, iconos, diagramas e ilustraciones que se pueden escalar sin perder calidad.
- [**Audacity**](https://www.audacityteam.org/): programa para grabar, cortar y editar audio. Es útil para trabajar con voz, música y otros archivos de sonido.
- [**OBS Studio**](https://obsproject.com/): permite grabar la pantalla o transmitir vídeo en directo. Se usa, por ejemplo, para tutoriales, presentaciones y emisiones.
- [**Blender**](https://www.blender.org/): suite de creación 3D para modelar, animar y renderizar escenas; también incluye herramientas de edición de vídeo y composición.
- [**Visual Studio Code**](https://code.visualstudio.com): editor de código de Microsoft con terminal integrada, depuración y un amplio catálogo de extensiones. El código base Code–OSS es abierto, pero la distribución oficial de Microsoft incluye componentes propios; revisa también la telemetría y las extensiones que instales.

# Tails
[Tails](https://tails.net) es un sistema portátil que se inicia desde una memoria USB y dirige las conexiones de red por Tor. Está diseñado para no guardar por defecto la sesión en el disco del ordenador; puedes configurar almacenamiento persistente cifrado si necesitas conservar archivos. Es útil para tareas puntuales donde importan la privacidad y la reducción de rastros locales, pero Tor y Tails no garantizan anonimato: iniciar sesión en cuentas personales o revelar datos identificativos puede vincular la actividad contigo.

# Qubes
[Qubes OS](https://www.qubes-os.org) prioriza la compartimentación: separa actividades y aplicaciones en máquinas virtuales aisladas para limitar el impacto si una de ellas se ve comprometida. Es una opción avanzada, con mayor complejidad y requisitos de hardware; no sustituye las actualizaciones ni evita todos los ataques.
