# Recomendaciones

## Navegador
- [Firefox](https://www.mozilla.org/firefox/): Para quien busca un navegador general, flexible y compatible con muchas extensiones. Conviene revisar los ajustes de privacidad y añadir un bloqueador de contenido.
- [Brave](https://brave.com/): Para quien quiere bloqueo de anuncios y rastreadores activado de entrada, con buena compatibilidad con sitios y extensiones de Chrome.
- [LibreWolf](https://librewolf.net/): Para quien quiere Firefox con ajustes más restrictivos desde el inicio y no le importa ajustar algunos sitios manualmente. Principalmente para escritorio.
- [Mullvad Browser](https://mullvad.net/en/browser): Para quien busca reducir el rastreo por huella digital. No incluye una VPN y se puede usar sin Mullvad VPN.
- [IronFox](https://ironfoxoss.org): Para quien usa Android y quiere un navegador basado en Firefox, orientado a la privacidad.

## Buscador
- [DuckDuckGo](https://duckduckgo.com/): Para búsquedas sencillas de páginas, imágenes y mapas.
- [Startpage](https://www.startpage.com/): Para quien prefiere resultados con tecnología de búsqueda de Google y búsquedas no personalizadas.
- [Brave Search](https://search.brave.com/): Para quien prefiere un buscador con índice propio.

## Proveedores y autenticación

### Proton: 10€/mes o 120€/año
[Proton](https://proton.me/) es un ecosistema de privacidad que integra correo electrónico, VPN, gestor de contraseñas y almacenamiento en la nube. Todas sus herramientas utilizan cifrado de extremo a extremo, permitiendo gestionar la comunicación, los archivos y las credenciales de forma segura y centralizada en una sola cuenta.

### Servicios separados: 5€ VPN + 3€ Correo + 1.65€ Gestor = 9.65€/mes o 116€/año
- [Tuta Mail](https://tuta.com): Para quien prioriza correo y calendario cifrados. El plan gratuito sirve para empezar; los planes de pago añaden capacidad y funciones. **Precio:** gratis, 3€/mes, 8€/mes.
- [Mailbox](https://mailbox.org/en/): Para quien quiere un correo tradicional (IMAP, POP3, PGP), calendario, contactos y herramientas de oficina. **Precio:** 1€/mes, €3/mes, €9/mes.
- [Cock.li](https://cock.li/): Para quien busca un servicio de correo sencillo, gratuito y con dominios poco convencionales; también ofrece mensajería XMPP. **Precio:** gratis.
- [Mullvad VPN](https://mullvad.net/en): Para quien quiere una VPN con una tarifa mensual sencilla y sin comprometerse a un plan largo. **Precio:** €5/mes.
- [Bitwarden](https://bitwarden.com/): Para quien busca un gestor de contraseñas independiente, código abierto, con plan gratuito y sincronización entre dispositivos. **Precio:** gratis, 1.65€/mes
